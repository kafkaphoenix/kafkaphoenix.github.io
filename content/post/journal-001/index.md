## Preface

Hello! My name is Javier! I'm a Software Engineer by day, with a passion for graphics programming and game development. To be honest from the start: I don't have much experience in graphics programming or game development beyond some hobby projects and following tutorials. However, I have a strong foundation in programming and software development principles, which I believe will help me learn and grow in this area. I also think that a full voxel engine tutorial from scratch is something that’s missing on the internet. By making mistakes and learning from them as a beginner, I hope to provide others with the motivation and resources to start their own journey in graphics programming and game development.


## Disclaimer: about AI usage

I'm not an AI, bro. All the content here is written by me; I just use AI tools to help with grammar and spelling. When working on the code, I write all the code myself (that means no Cursor, Claude, etc.). I do have code completion enabled in my IDE, but I don't use it that much. After working with Copilot for a few years, I found it more distracting than helpful. 

I find that asking ChatGPT for specific problems or new ideas can be useful, especially if backed up with references. But when you don’t understand something, it’s better to backtrack and do some research on Google or YouTube. Once you build a foundation and have a clear idea of what you want to do, you can better judge whether what the AI suggests makes sense. Letting an AI write code for you when you don’t understand the problem is a recipe for disaster.

One problem I see nowadays is the AI-fueled bloating of the internet with low-quality content and non-optimal or non-working code/tutorials. I want this to be a real project, where I learn and share my experience as a beginner in graphics programming and voxel engines.

## Introduction

The idea for this project was born out of a desire to create a simple voxel engine. I have already have a WIP(work in progress) engine called [newleaf](https://github.com/kafkaphoenix/newleaf), which uses OpenGL, C++, and ECS with EnTT. It also supports model loading via Assimp and includes a debugging interface with ImGui. However, I wanted to create something much more minimalistic, focusing purely on the core concepts of voxel engines. The goal is to experiment with different algorithms and ideas—procedural tree and mountain generation, biomes, optimization techniques, and other fundamental mechanics (without getting distracted by complex engine architecture or design patterns). Eventually, I plan to port these ideas into my main engine.

Over the years, I have dabbled in graphics programming and game development, but I have never built a voxel engine from scratch. This project aims to fill that gap in my knowledge and provide a solid foundation for future exploration in this area. I plan to document every day I work on it, including the resources I use and the challenges I face.

I want to take the best of all the tutorials and resources I’ve collected and apply them in an organized, practical way. I have a lot of links and tutorials saved that I will be referencing and sharing here. This journal will let me turn that knowledge into a step-by-step project, rather than just following demos or fragmented lessons. Too many tutorials either show only a brief overview without follow-up or go very deep on one topic without explaining how to integrate it into a full project from scratch.

The README provides a summary of the project structure and planned features, though it will continue to evolve. This journal aims to link to daily commits with brief explanations of what was done, the resources used, and the challenges encountered, so others can follow along and learn from my experience.

There will be no strict schedule; I will work on this whenever I have free time and motivation. I will, however, try to update this journal as often as possible.

Sometimes, I will write more detailed documents in the docs/ folder about specific topics or techniques (especially when I have to choose between multiple approaches or encounter something worth a deep dive).

So that’s it for now! I’m excited to start this journey and share my experiences with you. Let’s build a voxel engine from scratch, one day at a time!
